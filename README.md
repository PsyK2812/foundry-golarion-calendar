# Golarion Calendar

A Foundry VTT (v13+) module with the Absalom Reckoning calendar of Golarion:
draggable date & time widget that expands into a month view, configurable time buttons,
GM and player notes, moon phases with Golarion full moon names, seasonal sunrise/sunset,
and automatic scene darkness that follows the time of day and the moon.

Install via manifest URL:
https://github.com/PsyK2812/foundry-golarion-calendar/releases/latest/download/module.json
